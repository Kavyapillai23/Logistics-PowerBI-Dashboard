# Logistics Power BI Dashboard

## 📊 Overview
This repository contains an interactive **Power BI dashboard** that provides a comprehensive view of logistics performance.  
It integrates multiple data sources to analyze **employees, customers, shipments, payments, and overall logistics KPIs** in one place.

## 🚀 Features
- **Funnel Chart**: Highlights employee shipment completion stages with conditional formatting to show drop‑offs clearly.  
- **Employee Benchmarking**: Compare performance across designations and domains.  
- **Customer Segmentation**: Retail, Wholesale, and Internal Goods breakdowns with payment reliability insights.  
- **Shipment Analysis**: Charges by domain/content, delivery outcomes, and service types.  
- **Payment Trends**: Revenue by mode (Card vs COD), transaction values, and membership impact.  
- **Logistics Overview**: High‑level KPIs including revenue, shipment charges, and membership counts.
